# SICODETRI

**Authors**:       Carlos Nole

**Document Version**:  1.0.0

**Supported Spring Boot Version**: 3.2.8

### Descripción y funciones
Aplicación Web monolitica que permite realizar la conciliación de la Depreciación Tributaria vs Financiera de los Activos Fijos.

### Prerequisitos
Siga las siguientes instrucciones para iniciar el proyecto como ejemplo de consumo.
- JDK 17
- Maven 3.9.6

### ¿Cómo usar?
- Construir el proyecto (Build Project)
- Hacer clean install con maven
- Hacer clic en Run
